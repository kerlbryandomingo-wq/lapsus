# Lapsus 0.1.0

First release of Lapsus, a focused Windows browser for the AMA Discipulus student portal.
Lapsus is an independent student project and is not affiliated with AMA Education System.

## Highlights

- Opens the Student Portal in genuine fullscreen with the Lapsus controls hidden (hover the top
  edge to show them, F11 to leave). Settings > Window switches to a maximized window.
- Secure browsing: HTTPS only (with a per-session exception), blocked local-file and script
  links, pop-ups only after a click, site permissions that ask first.
- Bookmarks, history, downloads, find in page, zoom, light and dark themes, focus mode.
- Study Assistant (Ctrl+K) for explaining material you choose to send, with your own OpenAI or
  Anthropic key or an offline demo mode. You review the exact text before it is sent.

## Install

- `Lapsus-Setup-x64.exe`: installer for your Windows account, no admin rights needed.
- `Lapsus-Portable-x64.exe`: run without installing.

Windows 10 22H2 or Windows 11, 64-bit. This build is not code-signed, so Windows may warn that
the publisher is unknown. Verify the file with `SHA256SUMS.txt` before running it.

## Known limitations

- Not yet tested on the real Discipulus portal from the build environment.
- No automatic updates; download new versions from the Releases page.
- No Safe Browsing warnings for known malicious sites.
