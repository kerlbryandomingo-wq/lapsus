# Lapsus

A focused Windows browser for the AMA Discipulus student portal, by KRLBRYN.

Work in progress. See the open pull request for the first release.

## Sophia for Android

The Android edition lives in [`android/`](android/README.md) and is called **Sophia** (*Browse. Learn. Understand.*). It was formerly "Lapsus for Android". The Windows app keeps the Lapsus name.
